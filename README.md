# etak64n 👋

🛠️ Self-hosted services, command-line tools, and libraries, mostly in Go, TypeScript on Cloudflare Workers, and Rust.

- 🌟 [albireo](https://github.com/etak64n/albireo): a private video library on Cloudflare Workers, with the videos in your S3-compatible bucket.
- 🌟 [polaris](https://github.com/etak64n/polaris): a dashboard on Cloudflare Workers that shows how much of each Free plan limit is left, with the cost and metrics.

# etak64n 👋

🛠️ Self-hosted services, command-line tools, and libraries, mostly in Go, TypeScript on Cloudflare Workers, and Rust.

## ✨ Featured

- 🎬 [albireo](https://github.com/etak64n/albireo): a private video library on Cloudflare Workers, with the videos in your S3-compatible bucket. ▶️ [Live demo](https://etak64n.github.io/albireo/)
- 📊 [polaris](https://github.com/etak64n/polaris): a dashboard on Cloudflare Workers that shows how much of each Free plan limit is left, with the cost and metrics. ▶️ [Live demo](https://etak64n.github.io/polaris/)

## 🧰 More projects

- 🎞️ [deneb](https://github.com/etak64n/deneb): a self-hosted video API in one Docker image, from upload to HLS and captions.
- ⏱️ [kickd](https://github.com/etak64n/kickd): an always-on agent that runs commands on cron schedules, webhooks, and file changes.
- 📅 [calx](https://github.com/etak64n/calx): a macOS command-line tool for Apple Calendar.
- 🕰️ [gocron](https://github.com/etak64n/gocron): a Go library that parses cron expressions and works out when they fire.
